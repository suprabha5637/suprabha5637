# 🚀 First Projects

## 🤖 AI-Based Internship Recommendation Engine

**AI-powered recommendation platform for matching candidates with relevant internship opportunities.**

- 🎯 Matches candidates with internships based on **skills, education, interests, and location**
- 🧠 Uses **Jaccard Similarity, TF-IDF, and Cosine Similarity**
- 🔎 Applies **Natural Language Processing (NLP)** techniques
- ⚙️ Developed REST-based application architecture
- 🗄️ Uses MongoDB for data management
- 🌐 React.js frontend with backend services

**Tech Stack:**  
`Python` `Flask` `React.js` `Node.js` `MongoDB` `Pandas` `Scikit-learn` `NLP` `Tailwind CSS`
